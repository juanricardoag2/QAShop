### Ejemplo de severidad y prioridad

| Severidad | Descripción                                              |
|-----------|-----------------------------------------------------------|
| Crítica   | Bloquea completamente una funcionalidad clave (ej. checkout no crea el pedido). |
| Alta      | Afecta una funcionalidad importante pero existe un workaround. |
| Media     | Afecta la experiencia pero no bloquea el flujo principal. |
| Baja      | Problema cosmético o de texto sin impacto funcional.       |

| Prioridad | Descripción                                    |
|-----------|--------------------------------------------------|
| Alta      | Debe resolverse antes del próximo release.        |
| Media     | Debe resolverse, pero puede esperar.              |
| Baja      | Se puede resolver cuando haya disponibilidad.     |
